# Tec Escola - Apresentacao institucional

Versao publica do site de apresentacao institucional da Tec Escola.

Site em producao: https://apresentacao.tecescola.grupotec.dev.br/

## Conteudo

- `index.html`: editor e visualizacao da apresentacao.
- `html2canvas.min.js`: suporte para gerar a imagem copiada pelo editor.
- `favicon-apresentacao.svg`: favicon do site.

## Uso local

Abra `index.html` em um servidor estatico ou publique o conteudo deste repositorio em qualquer hospedagem de arquivos estaticos.
